Detailed Description

Publishes the aggregated status of a robot process on /robot_status.

Parameters, declared on node:

  • robot_status.rate_hz (double, 1.0): publishing rate; 0 disables it.
  • robot_status.pose_topic (string, empty): a PoseWithCovarianceStamped topic (e.g. "amcl_pose") whose last pose is reported.
  • robot_status.battery_topic (string, empty): a BatteryState topic whose last message is reported.

The robot is node's namespace, and the capabilities come from collect.
